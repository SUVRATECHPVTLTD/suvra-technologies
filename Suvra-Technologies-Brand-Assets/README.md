## Usage
- 01-logos: transparent symbol and light/dark horizontal and stacked lockups. Dark means designed for dark surfaces; light means designed for light surfaces.
- 02-web: copy contents into Next.js public/ (or equivalent); link favicon.ico, apple-touch-icon.png and site.webmanifest. Google Search site icon: google-site-icon-512.png; use a crawlable stable URL and favicon link. Search display is not guaranteed. Google sign-in OAuth branding can use the square icon where accepted; not a Google trademark icon.
- 03-android: merge res/ into app/src/main/res; set manifest android:icon and android:roundIcon to mipmap resources. Adaptive foreground has extra safe-zone padding. Play Store listing icon is separate. Test masks in Android Studio.
- 04-ios: import AppIcon.appiconset into Assets.xcassets; verify target membership and Xcode build. App Store 1024 export is opaque RGB. No pre-rounded corners.
- 05-expo: copy images into project assets/ and merge app-config-example.json into existing app configuration. Do not overwrite unrelated settings.
- 06-admin: sidebar and login assets.
- 07-social: profile and Open Graph share image.

Palette: #071426 navy, #2563EB electric blue, #06B6D4 cyan, #F8FAFC platinum white, #94A3B8 slate, #0F172A dark surface. These are UI tokens; the original emblem's actual pixel colors are preserved in the master.
